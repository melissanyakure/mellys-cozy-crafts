## Website Generation Prompt: Melissa's Cozy Crafts

Build a warm, handmade-feel portfolio/shop website called **"Melissa's Cozy Crafts"** to showcase my handmade crochet pieces. Style: soft, earthy, cozy aesthetic — warm neutrals, cream/terracotta color palette, cursive or handwritten-style accent font for headings paired with a clean sans-serif for body text. Feel artisanal and personal, not corporate.

**Pages/Sections needed:**
1. **Hero** — Website name, a warm tagline (e.g. "Handmade with love, stitch by stitch"), and a featured photo.
2. **About** — Short bio: I'm a self-taught crochet artist creating one-of-a-kind wearable pieces and accessories, each made to order.
3. **Gallery/Shop grid** — Each item as a card with photo(s), name, description, and materials. Grid should be responsive (mobile-friendly).
4. **Contact** — Email and phone number, plus a simple contact form.
